# 질문 나무 (3차시)

「질문하는 힘 기르기」 3차시용 모둠 웹앱이에요. 2차시 「질문 룰렛 놀이」에서 모둠이 만든 질문을 불러와, 모둠 태블릿의 **질문 나무**에 옮겨 놓으며 질문의 종류를 나눠 봐요.

> **뿌리가 튼튼해야 가지가 뻗어요. 두 질문 모두 탐구에 꼭 필요해요.**

| 자리 | 뜻 |
| --- | --- |
| 🌿 가지 질문 | 알아낸 것으로 따져 보며 뻗어 나가는 질문 · 탐구의 출발점 |
| 🪵 기둥 | 가지일까, 뿌리일까? 함께 고민할 질문 |
| 🌱 뿌리 질문 | 찾아보면 알 수 있는 질문 · 탐구의 바탕 |
| 🧺 질문 바구니 | 아직 놓지 않은 질문 |

1. **준비**: 선생님이 2차시 CSV를 올리면 모둠별로 질문이 나뉘어요. (CSV가 없으면 질문을 한 줄에 하나씩 붙여 넣어요 → 모든 모둠에 같은 질문)
2. **입장**: 모둠 태블릿이 게임 코드나 QR로 들어와요. 시작 전에도 나무는 보여요.
3. **활동**: 시작하면 **우리 모둠 질문만** 질문 바구니에 담겨요. 모둠 친구들과 자유롭게 의논하며 질문을 끌어서 가지 · 기둥 · 뿌리에 놓아요. 다시 바구니로 돌려놓을 수도 있어요. 필요한 질문이 없으면 **새 질문 쓰기**로 더해요.
4. **공개**: 제한 시간은 없어요. 선생님이 **활동 끝!**을 누르면 모든 모둠 나무가 선생님 화면에 한꺼번에 공개돼요. 네 자리의 뜻이 함께 떠요.

- 차례 규칙과 3원칙 표시는 넣지 않았어요. (학급마다 다를 수 있어서) 가지 질문과 뿌리 질문을 1:1로 잇는 선도 없어요.
- **선생님은 준비할 것이 없어요.** 2차시와 같은 서버(2·3차시 전용)를 써요.
- 화면은 **노트북과 태블릿**(가로·세로)에 맞췄어요. 휴대폰은 고려하지 않았어요.
- 빌드 도구 없는 정적 웹사이트(HTML·CSS·JavaScript)예요. GitHub Pages에 올리면 바로 써요.
- 디자인(글꼴, 색, 고양이 궁금이, 버튼)은 1·2차시와 같아요.

## 학생 태블릿에서 옮기는 방법

- **끌어서 놓기**: 손가락이나 마우스로 질문 카드를 끌어 원하는 자리에 놓아요. 화면 위·아래 끝으로 끌고 가면 화면이 저절로 움직여요.
- **눌러서 옮기기**: 카드를 톡 누르면 "여기에 놓기"가 뜨고, 놓을 자리를 누르면 옮겨져요.
- **키보드**: 카드에서 `1` 가지 · `2` 기둥 · `3` 뿌리 · `0` 바구니

옮길 때마다 1초쯤 뒤 서버에 저장되고(화면 위 **저장됨**), 인터넷이 잠깐 끊기면 모아 두었다가 다시 보내요. 새로고침하거나 태블릿을 다시 켜도 그대로 이어져요.

## 선생님 화면 (전자칠판)

| 단계 | 선생님 화면 | 모둠 태블릿 |
| --- | --- | --- |
| 준비 | 2차시 CSV 올리기(모둠별 미리 보기, 빼고 싶은 질문 ×) 또는 질문 붙여 넣기 · 주제(선택) | 코드 입력 → 모둠 고르기 → 친구 이름(별명) |
| 대기실 | 게임 코드 · QR, 모둠마다 질문 개수와 태블릿 | 빈 나무와 바구니, "선생님이 시작하면 질문이 담겨요" |
| 활동 | 핵심 문장 · 네 자리의 뜻 · 모둠별 **놓은 질문 수** (나무 내용은 보이지 않음) · 잠깐 멈춤 · **활동 끝!** | 나무 + 질문 바구니 + 새 질문 쓰기 |
| 공개 | 모든 모둠 나무, 핵심 문장과 네 자리의 뜻, 모둠 나무 **크게 보기**(지울 질문 ×), **그림 저장**(PNG), **질문 내려받기 (CSV)** | "땡! 우리 모둠 질문 나무 완성" · 우리 나무 보기 |

## 불러오는 CSV (2차시에서 받은 파일)

2차시 「질문 룰렛 놀이」의 **질문 내려받기 (CSV)** 파일을 그대로 올리면 돼요. 이 열을 읽어요.

| 열 | 쓰임 |
| --- | --- |
| `질문` | 꼭 있어야 해요. (머리줄이 없으면 첫 칸을 질문으로 읽어요) |
| `모둠` | `1모둠`, `2` 처럼 숫자가 들어 있으면 그 모둠 바구니로 가요. 이 열이 없으면 모든 모둠에 같은 질문이 가요 |
| `활동` | `질문 룰렛` / `한 마디 바꾸기` (있으면 기록에 남겨요) |
| `번호` | 2차시 번호 (있으면 기록에 남겨요) |
| `대주제` | 첫 값을 주제 칸에 채워요 |

- 엑셀에서 저장한 파일(UTF-8, EUC-KR 모두)도 읽어요. 같은 모둠 안에서 똑같은 질문은 한 번만 넣어요.
- 한도: 모둠 1~8개, 모둠마다 질문 80개, 새 질문 30개, 질문 한 개 100자

## 4차시로 넘기는 CSV

공개 화면의 **질문 내려받기 (CSV)** 파일(엑셀에서 바로 열려요, UTF-8 BOM)은 이 열로 되어 있어요. 이 파일을 3차시에 다시 올려도 읽혀요.

| 번호 | 모둠 | 자리 | 질문 | 새 질문 | 2차시 활동 | 주제 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 1모둠 | 가지 | 쉬는 시간은 학생에게 어떤 영향을 줄까? | | 한 마디 바꾸기 | 학교 |
| 2 | 1모둠 | 가지 | 쉬는 시간에 무엇을 하면 좋을까? | ○ | | 학교 |
| 3 | 1모둠 | 기둥 | 쉬는 시간은 얼마나 길까? | | 질문 룰렛 | 학교 |
| 4 | 1모둠 | 뿌리 | 급식실은 몇 명이 들어갈 수 있을까? | | 질문 룰렛 | 학교 |

- **자리**는 `가지` · `기둥` · `뿌리` · `바구니` 중 하나예요. 모둠마다 가지 → 기둥 → 뿌리 → 바구니 순서로 적혀요.
- **새 질문**은 3차시에 새로 쓴 질문이면 `○`예요.

## 서버 하나를 모든 반이 함께 써요

| | |
| --- | --- |
| 서버 | 개발진이 Apps Script로 배포한 웹 앱 하나 (`js/config.js`의 `SERVER_URL`, 2차시와 같은 2·3차시 전용 서버) |
| 선생님 구별 | 브라우저마다 만들어지는 선생님 열쇠. 게임은 만든 브라우저에서만 열고 지울 수 있어요 |
| 보관 기간 | 게임을 만든 뒤 **24시간**이 지나면 게임 코드와 질문이 모두 지워져요 → 끝나면 CSV나 그림으로 저장 |
| 기록 | 서버 시트의 `3차시 질문 나무` 탭에 질문마다 한 줄 (자리, 옮긴 시각, 새 질문 여부) |

**연습 모드**: 선생님 화면 위쪽 "인터넷 없이 이 컴퓨터에서 연습해 보기"를 누르면, 이 컴퓨터의 여러 창에서 선생님 화면과 태블릿 화면을 미리 해 볼 수 있어요. (같은 서버 코드 `gas/Code.gs`를 브라우저 안에서 돌려요)

## 폴더 구성

```
index.html  teacher.html  student.html
css/app.css         1·2차시와 같은 디자인 + 질문 나무 화면
js/config.js        서버 주소, 보관 시간, 서버에 묻는 간격
js/content.js       핵심 문장, 네 자리의 이름과 뜻, CSV 읽기
js/treeview.js      나무 그리기, 질문 카드, 그림(PNG) 만들기
js/dnd.js           끌어서 놓기 · 눌러서 옮기기 · 키보드
js/api.js           서버 · 연습 모드와 이야기하기
js/r3api.js         3차시 기능 묶음
js/teacher.js       선생님 화면
js/student.js       모둠 태블릿 화면

```

## 개발진이 할 일

1. **서버**: 2·3차시는 1차시와 따로 만든 **2·3차시 전용 서버**(구글 시트 「질문하는 힘 서버 (2·3차시)」)를 써요. 주소는 이미 `js/config.js`의 `SERVER_URL`에 들어 있어요. 1차시 서버(체험 서버 · 복제용 서버)는 건드리지 않아요.
   - 서버 코드를 고칠 때는 그 시트에서 확장 프로그램 → Apps Script → `Code.gs`를 바꿔 저장 → **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. ('새 배포'를 누르면 주소가 바뀌어요)
   - 2차시 저장소의 `gas/Code.gs`도 같은 1.3.1이에요.
   - 새 버전을 배포하지 않으면 3차시 화면에서 "서버 코드가 예전 버전이에요"가 뜨고 게임 코드가 만들어지지 않아요. (1.3.0 서버는 제한 시간 없는 활동을 몰라서, 잘못 만들어진 게임은 바로 지워요)
2. 저장소 `question-tree`를 GitHub Pages로 올려요. (1·2차시처럼 `lona10048-hub.github.io/question-tree/`)
3. 보관 시간이나 한도를 바꾸려면 `gas/Code.gs`의 `TRIAL_TTL_MS`, `R3_LIMIT`과 `js/config.js`의 `SERVER_RULES`, `js/content.js`의 한도를 같이 고쳐요.

## 시험해 본 것

- 서버 코드: 3차시 기능(만들기 · 모둠별 질문 나누기 · 입장 · 시작 전 질문 숨기기 · 저장 · 중복 저장 막기 · 새 질문 · 선생님 지우기 · 끝난 뒤 저장 막기 · 24시간 정리)과 1·2차시 기능을 Node에서 시험
- 화면: 가짜 서버(선생님 1 + 다른 선생님 1 + 모둠 태블릿 2)와 연습 모드(여러 창)로 CSV 올리기부터 공개 · 그림 · CSV까지, 다른 모둠 질문이 보이지 않는지, 다른 선생님이 남의 게임을 볼 수 없는지, 새로고침해도 이어지는지, 화면 끝에서 저절로 내려가며 끌어 놓기, 노트북(1024×768 · 1280×720 · 1366×768 · 1920×1080) · 태블릿(가로 1180×820, 세로 820×1180) 화면

실제 서버에 새 코드를 배포한 뒤 **태블릿 두 대로 한 번 해 보기**를 권해요.
